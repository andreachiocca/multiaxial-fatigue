## Loading scope

Current executable input: physical single-frequency CA tensors `S_mean + S_sin sin(t) + S_cos cos(t)`, with strains inferred elastically by the workbook importer. API availability and each law’s validity domain are separate. A repeating NP path can be nonsinusoidal, but the current importer cannot represent arbitrary periodic waveforms.

Use the loading/output columns above to screen candidate P/NP, mean-stress, strength-limit and life capabilities. These are source-domain assessments, not newly implemented capabilities. For proposed strain/plastic-work, gradient or probability use, inspect the required data and restrictions in the linked catalogue entry before coding.
