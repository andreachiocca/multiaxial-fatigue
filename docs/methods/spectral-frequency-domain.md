## Status and scope

This catalogue supports preparation of the FABER WG4.3 scientific review article and collaborative computational comparison. The present phase is CA multiaxial fatigue of plain/smooth geometries, without explicit notches, cracks, stress concentrations or significant gradients. Wider geometry/loading entries remain future/reference tracks, not current capabilities or commitments. See the independent [external-code inventory](../../docs/EXTERNAL_IMPLEMENTATIONS.md); external availability never changes WG4.3 completeness or validation.

**Fully implemented** means essential components are present, integrated and covered by numerical tests **for the named repository scope**. Some names explicitly identify repository adaptations; this does not certify reproduction of the unrestricted original criterion. **Partially implemented** means code exists with known essential gaps and may be enabled for a documented stage. **Not implemented** means no usable corresponding implementation exists. **Requires review** means active code exists but source completeness cannot yet be established; it is not silently counted as complete or as a proven coding omission.

Validation is independent: `not_tested`, `basic_numerical_tests`, `reference_examples_reproduced`, `independently_validated`. No current entry claims published-dataset reproduction or independent experimental validation. CAIM’s independent calculation of supplied equations is numerical verification. An execution sweep is not scientific validation.

CA = constant amplitude; P/NP = proportional/non-proportional. Repeating arbitrary paths are within the research scope; current workbook import supports a single-frequency harmonic cycle. Life from a fitted damage curve is distinct from a published native life law. [Audit](../../docs/method-audit.md) records shear conventions, clipping, material-property approximations and `_ext` variants. `_ext` is a repository maximum-damage selection, not another counted theory.
